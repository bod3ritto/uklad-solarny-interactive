# Interaktywny Układ Solarny

Niezależna, gotowa do wdrożenia aplikacja internetowa z serii interaktywnych projektów frontendowych.

## Technologie
- **React 19**
- **TypeScript**
- **Vite**
- **HTML5 Canvas / CSS3 / Framer Motion**
- **Lucide Icons**

## Uruchomienie lokalne
```bash
npm install
npm run dev
```

## Budowanie wersji produkcyjnej
```bash
npm run build
```
